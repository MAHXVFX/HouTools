Automation自动化批处理

入口:HouTools → Automation(以 Python Panel 浮动面板打开,可停靠进任意面板布局)

把要执行的操作排成任务队列,点 Start 后依序自动触发,适合收工挂机跑缓存、批处理等重复劳动。

任务类型

  • 按钮点击 — 对指定节点的指定参数(按钮)模拟点击,如 ROP 渲染、File Cache 写盘。
  • Flipbook — 按帧范围对视口拍屏输出序列图。
  • Webhook — 向指定 URL 发送请求,可用于联动智能家居(如跑完灯光提醒)。
  • 打开DW — 启动外部 Deadline Worker 处理当前工程。

使用要点

  • 后台线程执行,不阻塞 Houdini 界面;对 Houdini 的调用统一派发主线程,上一任务真正完成后才派发下一个——顺序语义有保证,主线程被解算阻塞多久就等多久。
  • 取消是协作式的,只在任务边界生效;点停止后按钮显示「停止中…」直到当前任务结束。
  • 节点可直接拖入参数路径框(原生投递)。
  • 配置 JSON 存 $HIP/HouTools_cfg/Automation_json/(跟工程走,多配置文件可切换),执行日志存 $HIP/HouTools_cfg/Automation_logs/。
  • 「打开DW」任务的软件路径在 settings/Automation_Config.json 配置(缺失时自动按默认值补建,可直接编辑);该任务执行前会强制保存当前工程。
  • Flipbook 帧范围支持灵活写法,解析失败时沿用场景当前范围并告警。
菜单 Reload Modules (Dev) 不会自动重建已打开的 Automation 面板(避免丢弃未保存的编辑),请点面板工具条自带的刷新按钮重建界面。

Paste as Object Merge粘贴为 Object Merge

入口:网络编辑器 HouTools 菜单 / 快捷键 Ctrl+Shift+V

在网络编辑器里 Ctrl+C 复制节点后,切到目标网络按 Ctrl+Shift+V,在鼠标位置创建引用节点(而非副本),颜色随源节点。按「目标上下文 × 源类别」自动选择引用方式:

复制的源 → 粘贴目标创建的节点(XXX = 源节点名)
SOP → SOPobject_merge Merge_XXX
SOP → OBJgeo XXX,内含 object_merge Merge_XXX
SOP → LOPsopimport SOP_XXX
SOP → COPsopimport SOP_XXX(仅新 COP,置 usesoppath=1)
SOP → DOPstaticobject Object_XXX
SOP → ROPfetch SOP_XXX(源为 File Cache 时路径追加 /render)
OBJ → SOPobject_merge Merge_XXX
OBJ → LOPsopimport SOP_XXX
LOP → SOPlopimport LOP_XXX
LOP → LOPfetch LOP_XXX
LOP → ROPusdrender XXX
  • 未列出的组合一律跳过(状态栏提示)。
  • 整次操作占用单个 undo 槽,Ctrl+Z 一步撤回。
  • 源路径取 OS 剪贴板文本;文本失效时退回内部剪贴板粘贴副本兜底(仅 SOP 网络)。
  • 键位在 HouTools → Paste Hotkey Settings 修改,也可用 Houdini 自带 Hotkey Manager(符号 h.pane.wsheet.houtools_paste_as_object_merge)。

Alembic Drag & Drop拖放导入 Alembic

入口:从资源管理器把 .abc 文件拖到网络编辑器

松手即在鼠标位置创建导入节点,免去 File → Import 的多步操作(基于 Houdini 官方 externaldragdrop 钩子):

拖放落点创建的节点(名称取文件名主干)
Object 层级(/obj)Alembic Archive,自动构建层级(等价 File > Import > Alembic Scene...)
SOP 层级(geo 内部)alembic SOP 节点
  • 支持一次拖入多个文件,纵向排开;整批一个 undo 槽。
  • 节点名自动清洗:中文等非法字符替换为 _,同名自动加数字后缀。
  • 非 .abc 文件不受影响;拖到参数框、视口等其他面板的行为与原生完全一致。
  • 文件损坏时由节点的错误旗标反馈(坏文件拖到 obj 层级可能静默不建子节点),创建操作本身不会失败。

Video to Sequence视频转序列图

入口:HouTools → Video to Sequence(独立窗口,进任务栏)

用 ffmpeg 把视频提取为图片序列,方便直接喂给 Houdini 的文件序列参数(如相机 Background Image、COP 纹理)。

  • 支持拖放视频文件到窗口,或浏览选择、手输路径。
  • 帧级进度显示;输出质量、起始帧编号、位数、文件名前缀可调。
  • 可选自动把输出序列设置到选中相机的 Background Image。
  • 转换前自动扫描输出目录中的同名旧序列并询问是否清除,防止新旧帧混杂。
  • 提取可随时取消(探测与转换阶段均可),取消时提示已写入帧数。
ffmpeg 优先使用 Houdini 自带的 $HFS/bin/hffmpeg,无需单独安装;如需指定版本,把 ffmpeg.exe 放到项目根目录即可优先使用。

Hdr LibraryHDR 环境贴图库

入口:HouTools → Hdr Library(独立窗口,进任务栏,可全局置顶)

HDR 环境贴图库浏览器:缩略图网格浏览、按文件夹分类、收藏,选中灯光后双击即完成贴图。

库组织

  • 库按「总目录 / 一级分类子文件夹」组织,左侧栏切换 全部 / ★ 收藏 / 各分类;侧栏右键可新建、打开分类文件夹,空分类也会列出,嵌套子文件夹归入第一级。
  • 首次使用在窗口内「更换目录」指定库目录;目录、缩略图大小、置顶、收藏都存 settings/hdr_library.json。

缩略图与贴图

  • 缩略图由后台线程池调 Houdini 自带 hoiiotool 按需生成(无需安装),缓存在库目录 .thumb_cache/;打开窗口不自动扫描,点「刷新」才比对补图(可暂停/停止),之后秒开;HDR 文件更新后旧缩略图自动失效重生成。
  • 选中一个或多个灯光后双击缩略图,HDR 路径批量写入灯光环境贴图参数——支持 OBJ envlight(Karma,自动关 skymap 程序化天空)、RenderMan dome 灯、LOP domelight 全家族(Solaris);其余灯型给出友好提示。
  • 右键缩略图:收藏 / 复制路径 / 打开所在文件夹;收藏项右上角带角标并计入侧栏计数。
缩略图尺寸固定(大小滑条决定),网格不随面板宽拉伸,面板宽窄只改变每列数量——与 Recipe Library 同一套排版逻辑。

Recipe Libraryrecipes 资产库

入口:HouTools → Recipe Library(独立窗口,进任务栏)

基于 Houdini 22 官方 recipes 的资产面板:卡片网格浏览、树形侧栏过滤、双击/拖拽应用到网络、Markdown 文档、数据导入导出。

浏览

  • 卡片显示缩略图、标签、版本、节点数,支持自定义主题色(右键「自定义颜色」)与收藏角标。
  • 树形侧栏按 全部 / 收藏 / 节点参数 / 子菜单 / 标签 / 网络层级 过滤。
  • 搜索框支持 # 前缀只搜标签(如 #pyro),多词 AND 匹配;自定义显示名(支持中文)同步参与搜索。
  • 预览缩略图点击放大:滚轮缩放、中键平移、双击或 Esc 关闭;GIF 显示动图,文档中的视频可播放。

应用

  • 双击卡片 = 官方工具架体验:参数照抄,视角不拉远(锚点落在视图外才整组平移到视图中心)。
  • 拖拽到网络 = 在落点对齐创建整组节点。
  • 应用前做网络层级匹配检查,不匹配时左下角状态栏给出中文提示(如 SOP recipe 进 LOP 网络)。
  • node / parm / decoration 预设需先选中目标节点。

元数据与文档

  • 库只加载「设置 ▸ 库目录」配置的用户文件夹(递归扫描 .hda),出厂库 / Labs 一律不显示;库启动时自动安装,Tab 菜单里的 session tool 从会话开始可用。
  • 自定义显示名、标签、颜色、收藏存 settings/recipelib.json,缩略图存 settings/recipe_thumbs/(相对路径存储,项目挪动不失效)。
  • 每条 recipe 可配 Markdown 文档(存 settings/recipe_docs/),确认/取消模式编辑,渲染支持 GIF 动图与视频;主面板有文档时直接渲染文档,无文档回退官方备注。
  • 设置缩略图支持两种来源:右键「设置缩略图」选图后框选裁剪(比例与卡片锁定),或「截取缩略图」屏幕框选。

数据交换

  • 「设置 ▸ 数据」导出/导入 zip 交换包(元数据 + 缩略图 + 文档 + HDA),打包带走、分享。
  • 导入按内部名合并:包内覆盖同名、本地独有保留、收藏取并集;与本地同名定义的 HDA 整文件跳过(避免同名定义二选一的不可预期)。

Paste Hotkey Settings快捷键设置

入口:HouTools → Paste Hotkey Settings

修改「粘贴为 Object Merge」的快捷键。点开窗口后按下任意键组合即捕获,确认后会话即时生效并持久化到 settings/hotkeys.json,每次启动 Houdini 自动应用。

  • 自定义键优先;其次尊重 Hotkey Manager 中已有的键位;最后落默认值 Ctrl+Shift+V。
  • 设置保存在本机 settings/ 目录下,换电脑或重装后重新设置一次即可。

Open Cache Folder打开缓存目录

入口:右键带 sopoutput 参数的节点(如 File Cache)→ Open Cache Folder [HT]

直接在资源管理器中打开该节点的缓存输出目录,免去翻参数、拷路径、开资源管理器的流程。

  • 取 sopoutput 参数的求值结果,打开其所在目录。
  • 缓存还没写出(目录不存在)时,自动上溯到最近存在的祖先目录。
  • 相对路径按 $HIP 解析,与 Houdini 读文件参数的语义一致。

Reload Modules (Dev)开发热加载

入口:HouTools → Reload Modules (Dev)

开发专用:重载所有 houtools 模块,改完代码无需重启 Houdini。已打开的工具窗口在 Reload 时自动关闭,重新打开即新代码;已打开的 Automation Python Panel 除外(由面板工具条的刷新按钮重建)。

  • 按模块导入顺序(即依赖序)重载;houtools/dev 框架自身不参与重载(改动它需重启)。
  • 菜单结构(两份菜单 XML)的改动是 H22 硬约束,仍需重启 Houdini 一次才能生效。

安装

  1. 把 HouTools 文件夹整个放到 Documents/houdini22.0/HouTools(与 packages/ 同级);
  2. 把项目根的 HouTools.json 放入 Documents/houdini22.0/packages/(文件夹放到其他位置时,改其中的路径即可);
  3. 启动 Houdini,顶部菜单即出现 HouTools。
仅支持 Windows:Automation 的窗口置顶用 Win32 API,部分工具的「打开所在文件夹」依赖 explorer。
